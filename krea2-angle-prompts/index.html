Frequently Asked Questions

What models was used to create these image examples?

The example images was generated with the default Krea 2 Turbo Checkpoint together with Qwen VAE + text encoder, no LoRAs.

Will these prompts work with other checkpoints or models?

Written for Qwen3-VL, which reads full sentences rather than word tags. They should work on other natural-language models like Qwen-Image, FLUX 1 & 2, SD 3/3.5, and DALL·E 3, but not on CLIP-based, tag-driven models like Pony Diffusion or SDXL/SD1.5.

Do these prompts guarantee consistent angle results every time?

No, AI generation produces different results each time. A fixed seed or a reference image is what keeps results consistent. The same prompt text will produce a slight variation in pose or angle with each generation. These prompts help steer the angle, but they don't guarantee perfect results on their own.

Why was this website created?

I looked all over the internet for angle prompts and never found a simple site like this one. Most places just dump a huge list of prompts for everything, and you have to dig through hundreds of unrelated ones to find the few that actually control the camera angles.

Can I contribute new angle prompts?

Yes, submissions are welcome via GitHub. Open a pull request or issue with your prompt and an example result, and it can be added as a card.
